# The 100-Day Plan

Prefer the daily-challenge format? Follow this schedule. It maps the
skill-based tracks in [`../CURRICULUM.md`](../CURRICULUM.md) onto 100 days so you
always know what's next — but unlike a rigid day-plan, if you miss a day you just
pick up the next lab. Nothing breaks.

> ~1–1.5 hours/day. Adjust freely. The goal is finished labs, not perfect streaks.

## Phase 1 — Foundations (Days 1–15)

| Days | Focus |
|------|-------|
| 1–3 | F1 Networking |
| 4–6 | F2 Security principles + MITRE ATT&CK |
| 7–10 | F3 Linux essentials |
| 11–14 | F4 Python for security |
| 15 | F5 Git & set up your fork + `PROGRESS.md` |

## Phase 2 — Network & Traffic (Days 16–27)

Track 1 labs: capture, read, scan, and write network detections.

## Phase 3 — Web Exploitation (Days 28–47)

Track 3 labs (SQLi ✅ first). One OWASP class every 1–2 days: attack → detect → fix.

## Phase 4 — Host Attack: Linux & Windows (Days 48–60)

Track 2 labs: enumeration, privilege escalation, persistence, and the detections.

## Phase 5 — Active Directory (Days 61–72)

Track 4 labs: Kerberoasting, pass-the-hash, lateral movement, DCSync + detections.

## Phase 6 — Detection Engineering & SIEM (Days 73–84)

Track 5 labs: ELK/Splunk, Sigma rules, ATT&CK mapping, dashboards, tuning.

## Phase 7 — Incident Response & Cloud (Days 85–93)

Track 6 (DFIR) + Track 7 (cloud misconfig → exploit → detect → harden).

## Phase 8 — Capstone & Career (Days 94–100)

| Days | Focus |
|------|-------|
| 94–96 | [Capstone](../capstone/) integration project (chain attack → defense) |
| 97–98 | Public CTF box + writeup (TryHackMe / HTB) |
| 99 | [Resume](../career/resume-template.md) from your labs |
| 100 | Publish portfolio, start applying |

---

Done early? Loop back and finish any track you skipped — there are more labs than
days here on purpose.
